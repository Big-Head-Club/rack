Resources

What the hundred games are built with, and where to look if you want to see how.

THE PROJECT

  • Build LedgerEvery project, measured from its own git history. Days, commits, lines, what is live.
  • RelayThe house template for daily link-first games. Two files of game, everything else built in.
  • Silly Ninjas artEvery sheet in the Silly Ninjas kit: the five ninjas with their poses and emotes, and ten worlds of props, ground and cast. Shared by Silly Ninja Defense and Silly Ninja Squares.
  • The trayOne script tag gives any game EJECT and SUBSCRIBE. It renders in a shadow root so it looks the same in every codebase and touches none of them.

THE CARTRIDGES

  • Ten Midjourney photographs of cartridges, cut out with real alpha.A cartridge outline is not something a rounded corner can fake, so the silhouette is computed: colour distance against a per-scanline ground model, forced convex, with a separate shadow test used only to trim inward.
  • Each label is the game running.The ledger photographs every live game. That plate is printed into the photo window of the shell the game was dealt.
  • The sound is synthesised.Web Audio, scheduled on the audio clock so the seat lands with the cart and the chord with the light.
